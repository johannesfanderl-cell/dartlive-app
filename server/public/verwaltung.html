Datensicherung

Sichert alles: Spielstände, Turnier/Spieltag, Statistik, Trainings-Bestenliste, Vereinsliga, Strichliste und Anmeldelisten – in einer Datei.

Sicherung einspielen: Ersetzt alle Daten auf diesem Gerät bzw. Server durch die Daten aus der Datei.

Automatisch: Der Server am Chromebook speichert jeden Tag eine Sicherung im Ordner dartlive/data/sicherungen (die letzten 30 Tage). Wenn du in den ChromeOS-Einstellungen den Ordner „Downloads“ für Linux freigibst, liegt zusätzlich eine Kopie in Downloads/Dart-Sicherungen – von dort kannst du sie z. B. in Google Drive ablegen.
